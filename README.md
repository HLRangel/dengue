# DengueInfoRP

Em 2025, começamos a coletar perguntas e respostas sobre a dengue com o intuíto de satisfazer os requisitos de nossa atividade avaliativa em Sistemas de Informação: a criação de um chatbot que poderia responder uma variedade de inquéritos sobre um certo tópico de forma adequada.

Seguindo a recomendação de nosso professor, utilizamos o DialogFlow ES, um sistema de classificação criado pela Google, que conseque associar pedidos a certas intenções. Mesmo com o sistema sendo proprietário, decidimos liberar os dados de nosso projeto para o bem público, já que a conscientização contra a dengue é de extrema importância. Os dados se encontram em representação textual, no formato de Notação de Objetos do JavaScript (JSON), e só é necessária uma consulta rápida para descobrir a estrutura de perguntas e respostas.

## Método de coleta

Os dados foram coletados de uma variedade de grupos, focando principalmente nos estudantes da própria universidade e na população local. Todos os participantes consentiram com o processo de treinamento a partir dos dados, e com a liberação dos mesmos.
